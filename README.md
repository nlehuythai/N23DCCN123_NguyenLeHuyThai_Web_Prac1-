# Mô tả 
1. Thành phần UI (Components)
- Navbar: Thanh điều hướng cố định.
- ProductCard: Card hiển thị sản phẩm với hiệu ứng hover.
- Button: Component nút bấm.

2. Chức năng chính
- Lấy dữ liệu (Data Fetching): Sử dụng Server Components để fetch dữ liệu trực tiếp từ API, tối ưu hóa tốc độ tải trang đầu tiên.
- Grid System: Hiển thị danh sách sản phẩm dạng lưới, tự động điều chỉnh số cột (1-4 cột) tùy theo kích thước màn hình (Mobile, Tablet, Desktop).
- Dynamic Routing: Xây dựng trang chi tiết sản phẩm dựa trên ID (/product/[id]), hiển thị thông tin chi tiết và mô tả sản phẩm.
